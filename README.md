# Personal Flow

自分専用のSuper Flow試作版です。普段はこの画面だけを使い、Codexは画面の修正や機能追加をしたい時だけ使います。

## できること（最初の版）

- URLを貼って保存する
- 記事タイトルと本文を取り出す
- Macの中だけで短い要点を作る
- 保存した記事を一覧で見返す
- 保存した情報からnoteの考える入口を表示する

## 起動方法

```bash
cd personal-flow
python3 app.py
```

ブラウザで `http://127.0.0.1:8765` を開きます。

この版はMacの中だけで動き、記事データも同じフォルダ内のデータベースに保存します。公開やアカウント作成は必要ありません。要点とnoteの入口は、まずAI料金なしで動く簡易版です。

## 次に足すこと

OpenAI APIをつなぐと、単なる要点ではなく、記事の価値・あなた向けの気づき・note向けの企画までAIが作れるようになります。
