# Personal Flow

自分専用のSuper Flow試作版です。普段はこの画面だけを使い、Codexは画面の修正や機能追加をしたい時だけ使います。

## できること

- URLを貼って保存する
- 記事タイトルと本文を取り出す
- Macの中だけで短い要点を作る
- 保存した記事を一覧で見返す
- 選んだ情報からnoteのテーマ案と下書きを作る
- 文章・画像・保存した情報からX投稿文を作る
- 不要な情報を、確認画面を見てから1件ずつ削除する

## 起動方法

```bash
cd personal-flow
python3 app.py
```

ブラウザで `http://127.0.0.1:8765` を開きます。

このアプリはMacの中だけで動き、記事データも同じフォルダ内のデータベースに保存します。外部公開やXへの自動投稿はしません。noteテーマや投稿文の作成には、サインイン済みのCodexを使います。APIキーは使いません。

テーマ作成で問題が起きた時、画面には原因別の短い案内を表示します。詳しい記録は同じフォルダの `personal-flow-diagnostics.log` に残ります。

テーマ作成は、選んだ記事の要点と短い抜粋だけを軽い専用処理へ渡します。時間切れや返答の形に問題があった時は、さらに短い材料で1回だけ自動的にやり直します。

テーマを選んだ後の「方向性を固める」も同じ軽い専用処理を使います。選んだテーマに必要な記事だけを渡し、失敗時は短い材料で1回だけ自動的にやり直します。

## 安全確認

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest -v
```
